# FlowGate Console

FlowGate API 网关管理控制台。当前处于**阶段 4：AI 提供商与模型映射**，并提供独立的 Mock 演示模式。

## 运行

要求 Node.js 22+、pnpm 11+。

```bash
pnpm install
cp .env.example .env.local   # Windows 可手动复制
pnpm dev
```

开发服务器默认运行在 `http://localhost:5173`，并将 `/api` 代理到
`http://127.0.0.1:8092`。需要先启动 FlowGate admin。

不启动后端也可以演示完整控制台：

```bash
pnpm dev:mock
```

`dev:mock` 使用 `.env.mock`（`VITE_DATA_MODE=mock`），所有数据由浏览器内
Mock 适配层提供。

```bash
pnpm typecheck
pnpm lint
pnpm build
pnpm build:mock
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `VITE_ADMIN_BASE_URL` | `/api/v1` | 管理 API 基地址；开发环境走 Vite 代理 |
| `VITE_ENV_LABEL` | `local` | 顶栏环境标识，不参与接口请求 |
| `VITE_DATA_MODE` | `live` | `live` 直连管理面；`mock` 使用浏览器内 Mock 适配层 |

## Mock 演示模式

- 入口：`pnpm dev:mock`（或 `pnpm build:mock`）。`.env.mock` 设置
  `VITE_DATA_MODE=mock`，优先级高于本地 `.env.local`。
- 数据源：`src/api/mock/` 内的内存种子数据；`http.ts` 在 Mock 模式下动态加载适配层，
  不发送任何 `fetch`，也不读取管理密钥。
- 模拟范围：健康检查、租户、API Key、服务、节点、路由、发布 / 回滚、AI 提供商与模型；
  状态码、校验文案、409 引用保护与发布校验按 Go 管理 API 的行为实现。
- 版本快照按真实格式生成（UTF-8 JSON → base64），发布与回滚会在内存中追加新版本。
- 演示数据仅存在于当前页面生命周期，刷新即重置。
- 演示模式在顶栏、侧边栏、总览与接入状态页都有明确标识；Mock 数据不会被描述为真实运行数据。
- 运行指标、请求日志、节点实时健康和用量查询仍标记为未接入 / 待后端接口。

## 数据与安全约定

- 不展示伪造的运行时数据。未接入的指标、日志、健康状态明确标记为“未接入”或“待后端接口”。
- 管理密钥仅保存在内存，或用户显式选择后保存在当前标签页的 `sessionStorage`；不使用 `localStorage`。
- 密钥通过 `X-Admin-Key` 请求头发送，不写入 URL、日志或页面文案。
- 401 统一触发管理密钥入口；网络失败进入不可达页；成功后恢复原路由。
- 所有请求经过 `src/api/http.ts` 统一处理超时、错误类型与响应解析。

## 已实现（阶段 1）

- 应用壳：深色侧边栏、顶栏面包屑、数据源状态徽标、响应式布局。
- 管理面连接生命周期：初始化、已连接、缺少密钥 / 密钥无效、不可达。
- 管理密钥入口：显示 / 隐藏、当前标签页记忆、清除确认、错误反馈。
- 运行总览：管理面真实健康状态、环境信息、数据源能力清单；不使用假指标。
- 接入状态页：密钥存储、数据源能力、管理 API 与指标端点的边界说明。
- 其他业务页面：显示计划范围与真实 API 依赖，明确标记为待实现。
- 404、渲染错误、空 / 错误 / 不可用状态组件。

## 已实现（阶段 2）

- 租户列表：真实 `GET /tenants` 数据、客户端名称 / ID 筛选、状态筛选、空 / 加载 / 错误状态。
- 租户新建与编辑：名称、状态、QPS / TPM 配额校验；停用租户前显示影响提示；提交失败保留服务端错误。
- 删除租户：二次确认，明确说明级联删除名下全部 API Key，成功后返回列表。
- 租户详情：配置摘要、状态与配额、API Key 数量；接口 404 / 失败 / 无效 ID 均有独立状态。
- API Key 管理：列表、创建、编辑、删除；状态与过期时间按真实字段派生，不展示后端未记录的最近使用时间。
- 一次性明文密钥：创建成功后单独弹窗展示，默认脱敏，可显式显示或复制；关闭后不保留、不写入存储或日志。
- API Key 配额与过期时间在运行时由 gateway 校验；停用租户或 Key、过期 Key 均会在界面提示。
- TPM 只有配额配置，管理 API 没有用量查询接口，因此不展示推测的已用量或剩余额度。

## 已实现（阶段 3）

- 服务治理：真实 `GET /services` 列表、名称 / ID / 状态筛选、空 / 加载 / 错误状态。
- 服务新建与编辑：全部可写字段（超时、重试、熔断、并发保护、过载策略）显式提交，按 PUT 全量覆盖语义处理；客户端校验整数范围、重试状态码与方法格式。
- 服务详情：配置摘要、节点列表、节点新增 / 编辑 / 删除，以及服务编辑与删除。
- 删除保护：服务仍被路由引用时展示管理面 409 的具体原因；删除服务会提示节点级联删除。
- 节点：地址必须是完整 http/https URL；界面提示 admin 的内网地址拦截与 `ALLOW_PRIVATE_UPSTREAM` 限制。
- 节点健康：`health_status` 明确标注为持久化字段，不把它当作实时健康状态，也不展示推测值。
- HTTP 路由：真实 `GET /routes` 列表、关键字 / 服务 / 状态筛选、创建、编辑、删除；服务下拉来自真实服务列表，不手填服务 ID。
- 路由字段：Host、路径、prefix / exact、方法列表、启用状态与路由级并发；说明匹配规则唯一性与服务端 409。
- 发布中心：发布当前配置、版本历史、版本快照详情、copy-forward 回滚。
- 版本快照：base64 `resource_snapshot` 解码后按服务 / 节点 / 路由分组展示，不展示未经验证的运行状态。
- 发布语义：说明只有 enabled 资源进入快照、发布校验规则、gateway 每 5 秒轮询最新 published 版本，以及控制台没有加载回执。

## 已实现（阶段 4）

- AI 提供商：真实 `GET /ai/providers` 列表、名称 / 端点 / 环境变量 / ID 与状态筛选、新建、编辑、删除。
- 提供商字段：名称、类型（仅 openai）、端点、上游路径、密钥环境变量名、Stream Usage、启用状态；客户端校验与后端名称字符集、URL、环境变量名规则一致。
- 密钥边界：管理 API 不返回 `api_key`，也不接受明文密钥写入；界面只配置环境变量名，并明确说明库内字面量密钥不可见、不可清除。
- 模型映射：真实 `GET /ai/models` 列表、关键字 / 提供商 / 状态筛选、新建、编辑、删除；提供商下拉来自真实列表。
- 模型字段：模型别名（主键，创建后不可改名）、所属提供商、上游模型名（留空使用别名）、启用状态。
- 运行时判断：根据 provider 启用状态、密钥环境变量与模型启用状态推导“已启用 / 不会加载 / 待确认密钥 / 提供商缺失”，不声称 gateway 已成功加载。
- 删除确认：删除提供商时提示会级联删除的模型数量；删除模型时说明客户端后续请求会失败。
- 变更传播：说明 AI 配置不经过发布中心，写操作使 `ai_config_version` 加 1，gateway 每 3 秒轮询版本并重建 AI handler；控制台没有加载回执。

## 已实现（工程化补强）

- 客户端分页：租户、服务、路由、发布版本、节点、API Key、AI 提供商与模型列表统一支持每页 10 / 20 / 50 条、上一页 / 下一页与范围摘要。
- 管理 API 的列表接口没有分页参数，因此分页与筛选都只作用于已加载的完整列表；筛选条件变化时回到第一页，数据减少时自动收敛到最后一页。
- Mock 适配层：独立于页面与业务逻辑的内存数据源，支持全量管理 API、真实格式版本快照与可交互写入；通过动态导入隔离，实时模式不会加载演示数据。
- 演示标识：全局横幅、顶栏徽标、侧边栏状态、总览与接入状态页共同标明 Mock 数据；未接入的运行指标与日志仍保持待接入状态。
- 路由级代码分割：页面按路由懒加载，应用壳与当前页面先加载；首次进入页面时显示轻量加载占位。入口 chunk 从约 521 kB 降至约 360 kB（gzip 从约 151 kB 降至约 114 kB），不再触发 Vite 的 500 kB 警告。

## 目录

```text
src/
  api/            HTTP、错误、管理密钥、查询客户端、契约类型
  api/mock/       演示用内存数据、请求适配器与快照编码
  app/            路由与全局 Provider
  components/     布局与通用 UI
  features/       连接状态、租户与 API Key、服务 / 路由 / 发布、AI 配置业务能力
  lib/            环境变量、时间、错误文案、能力清单
  pages/          运行总览、接入状态、服务与路由、发布中心、AI 模型路由、租户与 API Key、待实现页面
  styles/         tokens、基础、布局、组件、页面样式
```
